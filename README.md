# Koala Canvas releases (archived)

Koala Canvas is now **Koala POC Canvas**, open source under MIT:

**https://github.com/jespinosa19/koala-poc-canvas**

Install the current version:

```bash
npm i -g https://github.com/jespinosa19/koala-poc-canvas/releases/latest/download/koala-poc-canvas.tgz
koala-poc-canvas skill
```

The old `koala-canvas` command keeps working as an alias, and existing `.koala-canvas/` folders keep loading. `koala-poc-canvas skill` replaces the old skill and agents.

Docs: https://www.jordiespinosa.com/projects/koala-poc-canvas

The 0.2.x releases below stay available, but they are no longer updated.
